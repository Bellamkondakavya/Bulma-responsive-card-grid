# Responsive Card Grid Layout Using Bulma

## Overview

This project demonstrates the use of the Bulma CSS Framework to create a responsive card-based layout. The webpage includes multiple cards containing images, titles, descriptions, and action buttons arranged in a responsive grid.

The layout automatically adapts to different screen sizes, providing an optimal viewing experience on desktop, tablet, and mobile devices.

## Features

* Responsive card components
* Responsive grid layout using Bulma Columns
* Mobile-first design approach
* Image and text integration
* Hover effects for better user interaction
* Clean and modern user interface
* Cross-device compatibility

## Technologies Used

* HTML5
* CSS3
* Bulma CSS Framework

## Responsive Layout

### Desktop View

* Displays 3 cards per row

### Tablet View

* Displays 2 cards per row

### Mobile View

* Displays 1 card per row

## Bulma Classes Used

| Class        | Purpose                           |
| ------------ | --------------------------------- |
| columns      | Creates responsive grid container |
| is-multiline | Allows cards to wrap to new rows  |
| is-4-desktop | 3 cards per row on desktop        |
| is-6-tablet  | 2 cards per row on tablet         |
| is-12-mobile | 1 card per row on mobile          |
| card         | Creates card component            |
| button       | Styled action buttons             |
